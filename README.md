# 同城社区便民综合服务平台 MVP

这是一个基于微信原生小程序和微信云开发的同城社区便民服务平台 MVP。第一版目标是跑通核心业务闭环：用户下单、模拟支付、师傅接单、开始服务、完成服务、用户评价、管理员查看和管理数据。

## 当前阶段

当前已完成：

- 阶段一：架构与初始化
- 阶段二：登录与用户体系

已建立：

- 微信小程序基础目录
- 云函数目录
- 状态、角色、集合、云函数常量
- 前端工具函数
- 前端服务调用层
- 基础 UI 组件
- 用户端、师傅端、管理员端页面骨架
- `login` 云函数：首次登录创建用户、重复登录返回已有用户
- `user` 云函数：获取当前用户、更新资料、管理员改角色、禁用用户
- “我的”页面：微信授权登录入口、用户信息展示、师傅/管理员入口占位
- 骨架验收测试

## 阶段二说明

登录与用户体系使用 `users` 集合。第一版头像昵称使用默认值，手机号只保留字段，后续在地址或下单阶段再强制填写。

管理员初始化暂时采用手动方式：用户登录后，在云数据库 `users` 集合中将目标用户的 `role` 字段改为 `admin`。

微信开发者工具登录跑通步骤见：[docs/wechat-login-runbook.md](docs/wechat-login-runbook.md)。

## 微信开发者工具

使用微信开发者工具打开当前目录。项目配置文件为 `project.config.json`，小程序根目录为 `miniprogram/`，云函数根目录为 `cloudfunctions/`。

当前 `appid` 使用 `touristappid`，接入真实微信小程序账号时请在微信开发者工具中替换为实际 AppID。

## 云开发说明

小程序入口使用 `wx.cloud.DYNAMIC_CURRENT_ENV` 初始化云环境。创建真实云开发环境后，可在微信开发者工具中选择对应环境并部署云函数。

阶段二验证建议：

1. 创建 `users` 集合
2. 上传并部署 `cloudfunctions/login`
3. 上传并部署 `cloudfunctions/user`
4. 编译小程序
5. 进入“我的”页面
6. 点击“微信授权登录”
7. 打开云数据库 `users` 集合，确认用户记录存在
