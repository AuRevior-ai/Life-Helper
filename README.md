# 同城社区便民综合服务平台 MVP

这是一个基于微信原生小程序和微信云开发的同城社区便民服务平台 MVP。第一版目标是跑通核心业务闭环：用户下单、模拟支付、师傅接单、开始服务、完成服务、用户评价、管理员查看和管理数据。

## 微信开发者工具

使用微信开发者工具打开当前目录。小程序根目录为 `miniprogram/`，云函数根目录为 `cloudfunctions/`。

`project.config.json` 是开发者本地配置，可能包含真实小程序 AppID 和本地微信开发者工具设置，不应公开提交。首次本地运行前，请复制 `project.config.example.json` 为 `project.config.json`，再将模板中的 `touristappid` 替换为自己的 AppID 并填写本地配置；公开仓库和交付包只保留 `project.config.example.json`。不要擅自删除开发者本地 `project.config.json`，但公开交付时必须避免泄露真实 AppID 和 `project.private.config.json`。
