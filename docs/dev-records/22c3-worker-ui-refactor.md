# 阶段 22C3：师傅端 UI 重构阶段报告

## 1. 本阶段目标

阶段 22C3 用于记录师傅端 UI 重构的阶段性收尾。用户端 UI 已在 22C-2 收束，本阶段转向师傅端一级页面和身份进入链路，目标是让已审核个人师傅进入后看到统一、接近参考图的工作台体验。

本阶段不是完整的师傅端全量 UI 完成声明，而是确认师傅端 UI 重构已经完成了一大部分，可以作为阶段报告收尾。后续仍可继续处理师傅订单详情、收益明细、评价详情、资料编辑等次级页面。

本阶段继续遵守：

- `docs/ui-style-guide.md`
- `docs/ui-refactor-guardrails.md`
- 阶段 22A / 22B / 22C 系列建立的浅灰背景、白色圆角卡片、社区绿色主色、暖橙金额、胶囊按钮和柔和阴影体系

## 2. 本阶段完成范围

## 3. 关键 UI 调整

### 3.1 师傅端“我的”

- 页面切换为自定义导航风格，延续参考图中的大标题、副标题、白色卡片和柔和阴影。
- 师傅头像使用本地默认占位图，不再显示灰色头像占位。
- 增加认证师傅标签、评分、本月完成单量、接单状态、服务范围、统计卡片和菜单列表。
- 所有字体按真机反馈整体减小一号，避免实机上显得过重或拥挤。

### 3.2 接单大厅

- 重构为“状态卡 + 筛选栏 + 订单卡”的结构。
- 筛选栏使用横向 `scroll-view`，解决“可上门优先”被截断的问题。
- “距离优先”“3km以内”“可上门优先”等筛选胶囊已可点击，当前只保留占位交互，不做真实筛选逻辑。
- 接单按钮宽度、右侧列和卡片 grid 已收紧，修复按钮飞出屏幕的问题。
- 图片素材按用户要求暂留空，使用固定尺寸浅色占位块。

### 3.3 我的订单

- 页面标题调整为“我的订单”，副标题为“查看已经由你接下的服务订单”。
- 增加横向状态 tabs：全部、待上门、服务中、待完成、已完成。
- 增加状态与时间范围筛选卡，时间范围当前展示“本周”，交互暂为空。
- 订单卡改为师傅端专属结构，不再复用旧通用 `order-card`。
- 卡片展示服务名、派单标签、时间、地址、距离、联系人、订单状态、订单金额和查看详情/主操作按钮。

## 4. 进入师傅端逻辑调整

本阶段对“个人师傅端”入口做了必要的体验修正：

1. 普通用户进入“我的”页面。
2. 点击“选择登录身份”。
3. 选择“个人师傅端”。
4. 展示审核状态。
5. 若审核通过，显示“您已通过审核，即将跳转到接单大厅”，3 秒后自动跳转师傅端接单大厅。
6. 若未通过，显示“未通过审核，请联系管理员”。

该调整只改变身份进入体验，不改变审核状态枚举、不改变 worker 云函数接口、不改变用户角色权限判定。

## 10. 核心逻辑说明

- 师傅端一级页面使用 `worker-tab-bar`，通过 `wx.redirectTo` 在师傅端一级页面之间切换，避免混用用户端全局 tabBar。
- 审核通过自动跳转使用 3 秒定时器，并在页面隐藏或卸载时清理，避免重复跳转。
- 接单大厅和我的订单页面只做展示字段归一化，例如金额、手机号脱敏、距离文案和状态文案，不改变后端业务数据。
- 筛选栏点击事件当前是 UI 占位，不执行真实筛选。
