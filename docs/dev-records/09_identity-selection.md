# 阶段 9：登录身份选择与三端区分优化

## 阶段目标

在初版 MVP 真实验证通过后，补齐“每次登录后可选择本次进入身份端”的体验，让普通用户、师傅/商家、管理员不再混在“我的”页入口中。同时为后续小区合伙人端、城市合伙人端预留位置。

## 本阶段完成内容

- 新增 `pages/role-select/role-select` 页面，提供五端身份选择：
  - 普通用户端
  - 师傅/商家端
  - 管理员端
  - 小区合伙人端（即将开放）
  - 城市合伙人端（即将开放）
- 登录成功后自动跳转到身份选择页。
- “我的”页调整为账号中心，只保留账号资料、订单、地址和“选择登录身份”入口。
- 管理员初始化能力迁移到管理员端选择流程中，仍通过 `claimInitialAdmin` 云函数完成。
- 师傅/商家端选择时：
  - 已是师傅角色则进入接单大厅。
  - 不是师傅角色则进入入驻/审核状态页。
- 管理员端选择时：
  - 已是管理员角色则进入管理首页。
  - 不是管理员角色则提示初始化首个管理员。
