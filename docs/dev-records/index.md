## 阶段开始检查规则

每次进入新阶段前必须先阅读：

1. `docs/dev-records/index.md`
2. 上一阶段记录文件
3. 当前遗留问题总表

如果存在会阻塞当前阶段的 P0 遗留问题，必须先处理或向用户确认处理方式。

每个阶段结束时必须：

1. 运行本阶段验证命令。
2. 更新对应阶段记录文件。
3. 更新本索引文件。
4. 创建 Git 提交。
