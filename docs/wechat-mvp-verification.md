# 微信小程序初版 MVP 验证清单

本文档用于 MVP 各阶段结束后的真实微信开发者工具验证。建议按顺序执行，每完成一步再进入下一步。

## 1. 项目准备

1. 使用微信开发者工具打开当前工程根目录。
2. 确认 `project.config.json` 中的小程序根目录为 `miniprogram/`，云函数根目录为 `cloudfunctions/`。
3. 当前 `appid` 仍是 `touristappid`。接入真实小程序账号时，在微信开发者工具中替换为你的真实 AppID。
4. 在微信开发者工具中创建或选择云开发环境。
5. 确认小程序端使用 `wx.cloud.DYNAMIC_CURRENT_ENV` 连接当前云环境。

## 2. 云数据库集合

在云开发控制台创建以下集合：

| 集合 | 用途 |
|---|---|
| `users` | 保存授权登录用户、角色和状态 |
| `service_categories` | 保存服务分类 |
| `services` | 保存服务项目 |
| `addresses` | 保存用户服务地址 |
| `orders` | 保存订单和服务状态流转 |
| `workers` | 保存师傅入驻、审核和服务信息 |
| `reviews` | 保存用户评价 |
| `admin_operation_logs` | 保存管理员订单状态调整日志 |
| `messages` | 保存站内消息和未读状态 |
| `payment_logs` | 保存支付请求、回调、成功、失败和重复通知日志 |

当前小程序端不直接读写数据库，主要通过云函数访问集合。第一轮验证可先使用默认集合权限，后续上线前再细化安全规则。

## 3. 云函数部署

在微信开发者工具中逐个上传并部署以下云函数：

1. `cloudfunctions/login`
2. `cloudfunctions/user`
3. `cloudfunctions/service`
4. `cloudfunctions/address`
5. `cloudfunctions/order`
6. `cloudfunctions/worker`
7. `cloudfunctions/review`
8. `cloudfunctions/admin`
9. `cloudfunctions/message`
10. `cloudfunctions/payment`

部署后建议重新编译小程序，再开始业务验证。

## 4. 管理员初始化

1. 进入“我的”页面，点击“微信授权登录”。
2. 登录成功后进入“选择登录身份”页面。
3. 点击“管理员端”。
4. 如果当前云数据库还没有管理员，在弹窗中点击“初始化”。
5. 页面提示成功后会进入管理首页。
6. 打开云数据库 `users` 集合，确认当前用户的 `role` 字段已变为 `admin`。

如果按钮提示管理员已存在，可打开云数据库 `users` 集合，找到目标用户记录，手动将该记录的 `role` 字段改为 `admin`。

## 5. 服务种子同步

1. 使用管理员账号登录后进入“选择登录身份 - 管理员端”。
2. 进入“服务管理”。
3. 点击“同步种子服务”。
4. 打开云数据库，确认 `service_categories` 与 `services` 集合已写入数据。
5. 回到首页和服务列表，确认分类、推荐服务、服务详情均能正常展示。

服务浏览当前会优先读取云数据库；如果服务集合为空，会回退代码内置种子数据。

## 6. 用户下单到评价闭环

1. 使用普通用户账号完成微信授权登录。
2. 在“我的 - 地址管理”新增服务地址，并设置为默认地址。
3. 从首页进入服务详情。
4. 点击“立即预约”。
5. 填写预约时间和备注，提交订单。
6. 在订单详情点击“模拟支付”。
7. 确认订单状态变为“待接单”。
8. 等师傅接单、开始服务并完成服务后，普通用户进入订单详情。
9. 点击“去评价”。
10. 选择 1-5 星评分，填写评价内容并提交。
11. 确认订单状态变为“已完成”。
12. 进入“我的 - 消息中心”，确认订单状态消息正常展示并可标记已读。

## 7. 师傅验证

1. 使用另一个用户账号完成微信授权登录。
2. 登录成功后进入“选择登录身份 - 师傅/商家端”。
3. 填写姓名、手机号、服务分类、服务区域和简介，提交入驻申请。
4. 管理员进入“师傅审核”，通过该申请。
5. 师傅账号重新进入“选择登录身份 - 师傅/商家端”。
6. 在接单大厅查看待接单订单。
7. 点击接单。
8. 进入师傅订单详情，点击“开始服务”。
9. 服务开始后点击“完成服务”。
10. 填写完工说明，可选择 1-3 张完工图片，提交完成服务。
11. 进入“收入统计”，确认已完成订单金额会汇总展示。
12. 进入“师傅中心 - 消息中心”，确认审核和评价消息正常展示。

## 8. 管理员验证

1. 管理员进入“管理首页”。
2. 确认用户数、订单数、待审核师傅数和完成订单金额能正常展示。
3. 进入“订单管理”，查看订单列表。
4. 进入订单详情，测试合法状态流转的手动调整，并确认 `admin_operation_logs` 写入操作记录。
5. 进入“用户管理”，确认能看到用户列表。
6. 选择一个普通用户，测试“禁用”操作。
7. 进入“服务管理”，测试服务上架和下架。
8. 进入“服务管理”，测试新增或编辑服务。
9. 进入“分类管理”，确认分类列表展示正常。
10. 进入“分类管理”，测试新增或编辑分类。

## 9. 验证完成标准

- 普通用户可以完成登录、地址管理、下单、模拟支付、评价。
- 师傅可以完成入驻、被审核、接单、开始服务、完成服务、查看收入。
- 管理员可以完成看板查看、师傅审核、订单管理、用户管理、服务同步与上下架。
- `users`、`service_categories`、`services`、`addresses`、`orders`、`workers`、`reviews` 均有对应业务数据。
- 管理员调整订单状态后，`admin_operation_logs` 有对应操作记录。
- `messages` 中能看到订单和审核相关站内消息。
- 小程序编译无阻塞错误。

## 10. 已知限制

- 当前默认仍使用模拟支付；阶段 13 已准备 `payment` 云函数、`payment_logs` 和支付结果页，真实支付需商户资料与回调地址配置后联调。
- 首个管理员可在小程序内初始化，后续管理员仍建议由已有管理员分配或手动调整。
- 管理员订单状态调整已写入操作日志，强制调整仅作为调试能力保留。
- 评价完成采用创建评价后再条件完成订单，并在完成失败时补偿删除评价；后续可按真实环境需要升级为云数据库事务。
- 订单下单阶段仍保留阶段性服务快照种子数据，后续可统一改为从 `services` 集合读取。
- 完工图片上传依赖微信云存储权限，需要在开发者工具和真机环境验证。
- 消息中心已支持点击订单消息跳转详情。
