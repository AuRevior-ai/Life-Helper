# 微信开发者工具登录跑通手册

## 目标

在微信开发者工具中打开当前项目，完成“我的”页面微信授权登录，并在云数据库 `users` 集合中看到自动生成的用户记录。

## 当前已准备好的代码

- 小程序入口：`miniprogram/app.js`
- 登录页面入口：`miniprogram/pages/profile/profile`
- 登录前端服务：`miniprogram/services/login.service.js`
- 用户前端服务：`miniprogram/services/user.service.js`
- 登录云函数：`cloudfunctions/login`
- 用户云函数：`cloudfunctions/user`
- 用户集合名：`users`

## 你需要准备的微信侧内容

1. 一个微信小程序 AppID。
2. 微信开发者工具。
3. 一个云开发环境。
4. 云数据库集合 `users`。

## 操作步骤

### 1. 导入项目

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前仓库根目录：`D:\use_as_desktop\小程序开发`。
4. AppID 填写你自己的小程序 AppID。
5. 确认小程序目录为 `miniprogram/`。

### 2. 创建云开发环境

1. 点击微信开发者工具顶部“云开发”。
2. 创建一个云开发环境。
3. 记住环境名称。
4. 当前代码使用 `wx.cloud.DYNAMIC_CURRENT_ENV`，在开发者工具中选择当前云环境即可。

### 3. 创建 users 集合

1. 进入云开发控制台。
2. 打开“数据库”。
3. 创建集合：`users`。
4. 第一版不需要手动创建字段，首次登录时云函数会写入用户记录。

### 4. 部署云函数

在微信开发者工具左侧文件树中：

1. 右键 `cloudfunctions/login`。
2. 选择“上传并部署：云端安装依赖”。
3. 右键 `cloudfunctions/user`。
4. 选择“上传并部署：云端安装依赖”。

### 5. 编译并登录

1. 点击“编译”。
2. 进入底部 tab 的“我的”页面。
3. 点击“微信授权登录”。
4. 如果出现授权弹窗，点击允许。
5. 页面应展示当前用户昵称、角色和状态。
6. 打开云开发数据库 `users` 集合，确认新增用户记录。

## 管理员初始化

第一版管理员初始化采用手动方式：

1. 先完成一次登录。
2. 打开 `users` 集合。
3. 找到你的用户记录。
4. 将 `role` 从 `user` 改为 `admin`。
5. 回到小程序，退出后重新登录，或清缓存后重新进入。
6. “我的”页面应显示管理员入口。

## 常见问题

### 点击登录提示云函数不存在

处理方式：

1. 确认已部署 `cloudfunctions/login`。
2. 确认已部署 `cloudfunctions/user`。
3. 确认当前云环境选择正确。

### users 集合没有数据

处理方式：

1. 确认 `users` 集合已创建。
2. 确认点击的是“微信授权登录”。
3. 查看云函数调用日志，确认 `login` 是否报错。

### 没有出现头像昵称授权弹窗

处理方式：

1. 确认是在真机或微信开发者工具里点击按钮触发登录。
2. 如果当前微信环境不返回头像昵称，登录仍可通过 openid 创建用户。
3. 后续可以用微信推荐的头像选择和昵称输入方式继续完善资料。

### AppID 是 touristappid

`project.config.json` 当前使用 `touristappid` 作为占位。真实云开发登录需要使用你自己的小程序 AppID。
